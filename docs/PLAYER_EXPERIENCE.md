# 当前玩家体验与可玩范围

## 定位

《通往异世界的列车》目前是一个**可完整体验基础 COC MUD 交互的教学剧本**，而不是已经完成的长篇开放世界。它的目标是在一轮约 20–40 分钟的游玩中，让新玩家理解文字 MUD 的观察、移动、NPC 对话、物品、技能、SAN、战斗、逃跑、存档和调查记录。

## 已验证的体验闭环

| 环节 | 玩家能做什么 | 主要命令 |
|---|---|---|
| 账号与车卡 | 注册/登录、选择消防员/列车员/记者 | 按登录和售票员提示输入 |
| 环境探索 | 查看场景、出口、人物和物品 | `look`、`go <方向>` |
| NPC 对话 | 获取玩法说明、剧情线索和职业引导 | `say <话题> <NPC ID>` |
| 物品调查 | 拾取、查看、使用关键道具 | `get`、`inv`、`look <物品>`、`use` |
| 状态与技能 | 查看 HP/SAN/技能，执行调查、急救、潜行 | `hp`、`perform <技能> [目标]` |
| 风险与战斗 | 面对怪物、攻击或撤退 | `kill <目标>`、`flee` |
| 进度管理 | 保存、恢复、查看私有案件和目标 | `save`、`journal`、`bye` |

## 当前主要路线

玩家从车站登记后到达月台，进入末班列车并在 6 号车厢学习基本规则。随后依次经历便签/地图调查、5 号车厢侦查、4 号车厢急救、3 号车厢黑暗与怪物、1 号车厢控制台和终点站离车。州街和无名旧书店提供《暴风之眼》的后续章节入口。

## 当前版本的独特体验

本修改版增加了 `journal`。它把“不可携带的证据”“当前目标”“失败后的代价”和“可行的替代动作”存为每个玩家独立的案件状态。玩家不必记住所有文字，也不会因为其他玩家先搜索书架而失去自己的《暴风之眼》入口。

在 3 号车厢，玩家可以使用侦查、开灯、潜行、战斗或撤退等不同方式处理威胁。失败有代价，但关键路径不会因一次失败永久中断；线索册会给出下一步建议。

## 已知边界

《暴风之眼》目前是一个有完整发现、线索和阅读入口的章节钩子，尚不是完整副本。后续扩展应优先使用私有案件状态、房间级事件、NPC 关系和多出口结局，而不是把小说文本线性搬进游戏。

## 如何试玩

阅读 [新手说明](player/新手说明.md) 后，从以下最短流程开始：

```text
look
say 你好 ticket_clerk
# 完成姓名和职业选择
go east
go east
look
say 帮助 mara_vane
journal
save
```
