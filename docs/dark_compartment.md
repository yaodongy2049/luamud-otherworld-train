# 《常暗之厢》MUD角色设计（3选1，适配Lua实现）

核心原则：3个角色技能互补（覆盖侦查、急救、潜行、灵感等模组推荐技能），各带专属剧情伏笔，数值贴合COC7规则，可直接嵌入之前的Lua玩家数据结构（PC），支持MUD交互触发专属剧情。同时结合各车厢场景，补充详细行为、解谜玩法及怪物对战逻辑，所有解谜与对战均关联角色技能，适配MUD交互需求。

## 角色1：末班电车乘务员 佐藤雪（生存型·辅助）

### 核心定位

熟悉电车结构，擅长急救与场景交互，能解锁专属线索，适合辅助队友、规避基础危险，是团队的“生存保障”。

### 基础数值（COC7标准，适配Lua PC结构）

```lua
PC = {
    name = "佐藤雪",
    job = "电车乘务员",
    str = 40, con = 65, dex = 55, int = 50, pow = 45, app = 60, edu = 55,
    san = 55, -- 常年值夜班，心理承受力略强
    hp = math.floor((con + pow)/2) = 55,
    skill = {
        侦查 = 40,
        聆听 = 60, -- 职业优势，擅长听车厢异常声响
        急救 = 70, -- 核心技能，远超普通水平
        潜行 = 35,
        话术 = 45,
        灵感 = 40,
        电车知识 = 80 -- 专属技能，解锁电车相关交互
    },
    room = 6, -- 起始位置（与模组一致）
    items = {}, -- 开局由幸运判定补充，额外自带「乘务员手册」
    exclusive = "乘务员身份" -- 专属标识，用于触发剧情
}
```

### 专属背景与伏笔

28岁，在墨田区电车线路工作3年，今晚本是她的末班岗，却莫名陷入循环。她隐约记得，一周前曾有乘客在6号车厢留下奇怪的便签（与模组起始物品呼应），且4号车厢的濒死乘务员是她的同事。

### MUD专属交互（Lua可直接调用）

- 与4号车厢「濒死乘务员」对话时，无需急救判定即可触发完整台词：「小雪……别开驾驶舱门……那东西不是我们能碰的……」（额外解锁线索，SAN无额外损失）。

- 使用「电车知识」技能检查车厢（如3号车厢黑暗、1号驾驶舱门），可获得提示：「3号车厢的电路开关在左侧扶手下方，能短暂开灯（但会吸引怪物）」「驾驶舱门除了钥匙，还能通过控制台强制解锁」。

- 开局幸运判定时，额外获得50%概率保留「乘务员手电筒」（微弱光源，可照亮3号车厢局部，不吸引怪物）。

### 专属背景与伏笔

32岁，专门调查都市怪谈与未解决案件，此次乘坐末班电车，是为了调查“近一个月来，多起末班电车乘客失踪案”。他的笔记本上，已经记录了3起失踪者的信息，且都提到了“车厢内的黑暗”“无法回头”。

### MUD专属交互（Lua可直接调用）

- 调查6号车厢「便签」时，侦查判定自动成功，额外发现：「便签背面有微小的印记，是一个扭曲的眼睛图案（奈亚标识）」（SAN\-1）。

- 使用「灵感」技能时，触发概率提升20%，例如在5号车厢可触发：「你闻到的铁锈味，混杂着一丝不属于人类的腥气」；在1号车厢可直接触发真结局前置条件（无需灵感≥70，只需≥50）。

- 使用「摄影」技能拍摄血迹、抓痕、怪物残影时，可获得“线索记录”，结局判定时可额外解锁隐藏描述（如真结局中，能看清神秘存在的轮廓）。

### 专属背景与伏笔

35岁，因一次火灾救援中目睹诡异场景（与常暗之厢有关）而退役，此次乘坐末班电车，是为了寻找当年火灾中失踪的战友——他的战友，正是4号车厢的濒死乘务员（兼职）。

### MUD专属交互（Lua可直接调用）

- 对抗3号车厢「听觉怪物」时，使用「格斗」技能，伤害\+2，且有30%概率击退怪物（无需额外判定）；若佩戴「消防手套」，可避免被怪物利爪划伤（HP无额外损失）。

- 检查5号车厢「水渍」时，可触发专属描述：「你认出这不是普通水渍，是消防水与某种粘稠液体的混合物，当年火灾现场也有类似痕迹」（解锁伏笔）。

- SAN损失时，自动减免10%（例如应损失3点，实际损失2点）；队友陷入危险时（如被怪物攻击），可触发“保护”动作，替队友承受50%伤害。

## 各车厢场景行为、解谜玩法及怪物对战逻辑（适配Lua MUD）

核心规则：每个车厢均设置「基础行为」「解谜任务」「危险触发」，解谜成功可解锁线索、规避危险或获得道具，失败则触发惩罚（SAN损失、怪物袭击等）；怪物对战与解谜深度绑定，需通过解谜选择（如利用环境、道具、角色技能）规避或削弱怪物，而非单纯战斗，贴合COC模组氛围，同时适配3个角色的技能特点。

### 一、6号车厢（起始车厢，解谜：便签密码与电车地图）

#### 可执行行为及后果

- 行为1：查看便签（必触发）—— 触发解谜任务，无直接惩罚；若放弃查看，后续无法解锁3号车厢关键线索，进入3号车厢时怪物袭击概率提升50%。

- 行为2：侦查车厢（使用「侦查」技能）—— 判定成功：发现车门旁隐藏的电车示意图（被部分涂抹）；判定失败：仅看到普通车厢环境，无法获得地图线索。

- 行为3：尝试回头（前往7号车厢方向）—— 触发「巨嘴吞噬」预警，进行「灵感」判定：成功（SAN\-1），察觉后方空间扭曲，无法前进；失败（SAN\-1d3），被黑暗吞噬一小块衣角，强制留在6号车厢，后续行动次数减少1次。

- 行为4：使用手机/手电筒—— 手机无信号（触发「灵感」判定，成功可察觉信号干扰异常）；手电筒（若有）可照亮车厢角落，辅助「侦查」判定（\+10%成功率），但不会吸引怪物。

#### 解谜玩法（核心：便签密码解读）

解谜触发：查看便签后，触发「解读便签」任务，便签正面写有「只管前进吧！已经没有退路了。」，背面隐藏密码（需通过技能判定解锁）。

- 常规判定：使用「侦查」技能（难度50），成功：发现便签背面有模糊字迹「第三个箱子里有藏着钥匙」（“箱子”指代车厢，提示3号车厢有钥匙）；失败：无法发现背面字迹，后续进入3号车厢需额外进行「侦查」判定才能找到钥匙。

- 角色专属判定：
            

    - 佐藤雪（乘务员）：使用「电车知识」技能（难度40），成功：额外解读出「箱子对应车厢编号，3号车厢钥匙与电路开关相关」，解锁3号车厢电路开关线索；失败：按常规判定处理。

    - 高桥凉（记者）：无需判定，自动发现便签背面的扭曲眼睛印记（奈亚标识），同时解读出密码，额外获得「失踪案相关线索」（SAN\-1）。

    - 松本健（消防员）：使用「侦查」技能（难度60），成功：仅解读出密码；失败：可使用「力量」技能（难度50）撕开便签，强行看到背面字迹，但触发SAN\-1（因暴力破坏线索产生不安）。

- 解谜奖励：成功解读密码，获得「3号车厢钥匙线索」，进入3号车厢后「侦查」判定\+20%；失败：无奖励，进入3号车厢后怪物袭击概率提升30%。

#### 危险触发与应对

无怪物，危险仅来自「回头尝试」和「行动超时」：KP可设定每个车厢3\-4次行动限制，超时后车厢开始扭曲，触发SAN\-1d3，强制前往5号车厢。

### 二、5号车厢（过渡车厢，解谜：水渍与报纸线索）

#### 可执行行为及后果

- 行为1：查看水渍（触发解谜）—— 无直接惩罚，不查看则无法解锁4号车厢急救线索。

- 行为2：侦查车厢（使用「侦查」技能）—— 判定成功：找到一张泛黄报纸；判定失败：仅闻到铁锈味，无额外发现。

- 行为3：聆听周围（使用「聆听」技能）—— 判定成功：听到4号车厢传来微弱的呻吟声（提示4号车厢有NPC）；判定失败：仅听到电车行驶声，错过NPC线索。

- 行为4：尝试回头（返回6号车厢）—— 触发「车厢吞噬」，进行「敏捷」判定：成功（SAN\-1d2），快速退回5号车厢；失败（SAN\-1d6），被黑暗吞噬部分身体，HP\-5，强制前进至4号车厢。

#### 解谜玩法（核心：水渍溯源与报纸解读）

解谜1：水渍溯源（关联4号车厢急救）

- 常规判定：使用「侦查」技能（难度45），成功：发现水渍中混有血迹和铁锈，判断为“伤者拖拽痕迹”，解锁4号车厢「急救」判定\+10%；失败：认为是普通电车漏水，无额外线索。

- 角色专属判定：
            

    - 佐藤雪（乘务员）：使用「电车知识」技能（难度35），成功：判断出水渍来自4号车厢乘务员室，且是“紧急制动时的拖拽痕迹”，额外获得「乘务员可能受伤」的提示；失败：按常规判定处理。

    - 高桥凉（记者）：使用「灵感」技能（难度40），成功：发现水渍中混有不属于人类的腥气，联想到失踪案线索（SAN\-1）；失败：仅解读出水渍的血迹属性。

    - 松本健（消防员）：无需判定，自动认出水渍是“消防水与粘稠液体的混合物”，联想到当年火灾现场，解锁专属伏笔，同时获得「血迹未干，伤者还活着」的提示。

解谜2：报纸解读（关联结局线索）

- 触发条件：侦查车厢成功，找到报纸。

- 常规判定：使用「侦查」或「图书馆利用」技能（难度50），成功：发现报纸日期是“第二天”，报道的正是当前发生的电车恐怖事件（提示场景为循环/梦境），SAN\-1；失败：仅看到报纸标题，无法获得关键信息。

- 角色专属判定：
            

    - 高桥凉（记者）：使用「摄影」技能拍摄报纸，自动解读所有内容，额外获得「失踪者均提到“巨嘴”」的线索，为7号车厢探索铺垫；失败：无额外惩罚。

    - 佐藤雪/松本健：使用「话术」（佐藤雪）或「灵感」（松本健）技能（难度55），成功：解读报纸核心信息；失败：SAN\-1（因无法理解报纸的时间悖论而不安）。

- 解谜奖励：两个解谜均成功，进入4号车厢后可直接获得「乘务员钥匙」线索；仅成功1个，需在4号车厢额外进行「侦查」判定才能找到钥匙；均失败，4号车厢无法找到钥匙，后续无法解锁1号车厢驾驶舱门（只能触发坏结局）。

#### 危险触发与应对

无怪物，危险来自「回头尝试」和「行动超时」：超时后车厢断电，视野变黑，触发「灵感」判定（失败SAN\-1），同时4号车厢乘务员状态恶化，后续「急救」判定难度提升20%。

### 三、4号车厢（关键车厢，解谜：乘务员救援与钥匙寻找）

#### 可执行行为及后果

- 行为1：救援乘务员（触发解谜）—— 必做行为，不救援则无法获得钥匙，后续无法解锁1号车厢；救援失败，乘务员死亡，触发SAN\-1d2，且无法获得关键台词线索。

- 行为2：侦查乘务员室（使用「侦查」技能）—— 判定成功：找到「乘务员钥匙」（解谜核心道具）；判定失败：未发现钥匙，需重新判定（每次判定消耗1次行动次数）。

- 行为3：检查黑屏电视（使用「灵感」技能）—— 判定成功：看到人脸残影（SAN\-1），获得「怪物无视力」的线索；判定失败：仅看到雪花点，无额外发现。

- 行为4：尝试回头（返回5号车厢）—— 触发「巨嘴吞噬」预警，车厢开始收缩，HP\-3，SAN\-1d3，强制留在4号车厢，直至完成解谜。

#### 解谜玩法（核心：乘务员急救与钥匙寻找）

解谜1：乘务员急救（关联钥匙线索与剧情伏笔）

- 常规判定：使用「急救」技能（难度60，COC7规则修正，仅急救可唤醒乘务员），成功：乘务员苏醒，说出关键台词「别开驾驶舱门……它在后面……」，同时提示「钥匙在我口袋里」；失败：乘务员死亡，无法获得台词线索，钥匙需通过「侦查」技能（难度提升至70）寻找。

- 角色专属判定：
            

    - 佐藤雪（乘务员）：无需判定，直接唤醒乘务员，获得完整台词（额外提示「驾驶舱控制台可强制解锁」），且「侦查」寻找钥匙时判定\+30%。

    - 高桥凉（记者）：使用「急救」技能（难度70），成功：唤醒乘务员，获得台词；失败：可使用「话术」技能（难度50）尝试唤醒（仅一次机会），成功则获得部分台词，失败则乘务员死亡。

    - 松本健（消防员）：使用「急救」技能（难度55），成功：唤醒乘务员（认出是失踪战友），获得台词，同时解锁「保护乘务员」的专属动作；失败：可使用「力量」技能（难度45）按压胸口急救，成功则唤醒（HP\-2），失败则乘务员死亡。

解谜2：寻找乘务员钥匙（解锁1号车厢核心道具）

- 触发条件：急救成功（乘务员提示）或急救失败（自行寻找）。

- 常规判定：使用「侦查」技能（难度60，急救成功则难度降至50），成功：找到钥匙（铜制，刻有电车公司标志）；失败：继续判定，每次失败消耗1次行动次数，行动超时则钥匙消失（触发坏结局伏笔）。

- 角色专属判定：


    - 佐藤雪（乘务员）：使用「电车知识」技能（难度30），直接定位钥匙位置（乘务员口袋），无需「侦查」判定。
