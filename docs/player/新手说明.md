# 《通往异世界的列车》新手说明

**适用版本：** 当前网页版本  
**适合对象：** 第一次接触文字 MUD、COC 或《通往异世界的列车》的玩家  
**阅读时间：** 约 8 分钟；首轮完整列车体验约 20–40 分钟

> 你并不是在阅读一篇固定小说，而是在一列会回应选择的列车上调查、交谈、移动与求生。最有用的习惯只有一句：**先观察，再行动；不确定时查看线索册。**

---

## 1. 这是什么游戏？

《通往异世界的列车》是一款浏览器可玩的中文文字 MUD。你通过输入短命令探索地点、和 NPC 交谈、收集物品、使用技能，并在遭遇未知现象时维持身体与理智。

它采用 COC（克苏鲁风格调查）玩法的核心结构：你不必，也通常不应该把所有问题都用战斗解决。线索、观察、交谈、撤退和保存进度，往往比硬碰硬更重要。

当前教学剧本从车站与列车开始，依次教会你对话、移动、背包、状态、技能、战斗、逃跑、存档与线索追踪。之后可以进入州街、无名旧书店，并发现《暴风之眼》的后续章节入口。

---

## 2. 开始前：登录、创建角色与安全建议

打开游戏网页后，先输入用户名。用户名建议仅使用英文、数字或下划线，例如 `meike_01`。新用户名会被要求设置密码并再次确认；已有用户名会直接要求输入密码。

请使用**专门为本游戏创建的密码**，不要复用邮箱、学校、银行、社交平台或其他重要账户的密码。网页入口已经使用 HTTPS，但游戏账号仍应被当作独立的娱乐账号管理。

每个用户名对应一个角色和一个持续更新的存档。你不需要输入 `load`：下次使用同一用户名登录时，系统会自动恢复地点、HP、SAN、技能、背包、案件线索和剧情进度。

## 3. 你第一次进入时应该做什么？

第一次登录会在**车站入口大厅**醒来。先输入：

```text
look
```

你会看到场景描述、出口方向、房间里的 NPC 和物品。每个对象后通常会有方括号 ID，例如：

```text
售票员 [ticket_clerk]
```

当命令需要指定对象时，优先使用这个 ID，最稳定。

大厅里请先和售票员交谈：

```text
say 你好 ticket_clerk
```

售票员会依次询问你的姓名和职业。之后直接输入回答即可，不必每一句都重复 `say`。职业只能从以下三项中选一个：

| 职业 | 初始优势 | 推荐给谁 |
|---|---|---|
| **记者** | 侦查、灵感、话术较高；能看到少量额外调查线索 | 喜欢观察、对话和解谜的玩家 |
| **消防员** | 格斗、急救、潜行较强；在危险场景中容错较高 | 想体验战斗、救援和直接行动的玩家 |
| **列车员** | 急救、聆听、电车知识较强；对列车机关有专属理解 | 喜欢场景机制、路线和环境谜题的玩家 |

例如选择记者：

```text
记者
```

身份确认后，系统会自动保存一次，并提示你前往月台：

```text
go east
```

月台上再次向东进入末班列车：

```text
go east
```

随后角色会短暂沉睡，并在 **6 号车厢**醒来。

## 4. 最重要的三条原则

### 4.1 先 `look`，再决定下一步

每到新地点，第一条推荐指令都是：

```text
look
```

`look` 会显示场景、出口、人物、物品和可执行的操作提示。不要只凭直觉向某个方向连续移动；游戏会把可调查对象和风险写在房间描述中。

### 4.2 先问 NPC，再猜命令

NPC 往往知道本区域的规则。看到 NPC 后先输入：

```text
say 帮助 <NPC的ID>
```

例如在 6 号车厢：

```text
say 帮助 mara_vane
```

玛拉会告诉你可询问的主题。你可以进一步输入：

```text
say 理智 mara_vane
say 检定 mara_vane
say 逃跑 mara_vane
say 存档 mara_vane
say 列车 mara_vane
```

如果刚刚和某个 NPC 开始连续对话，通常也可直接输入主题，例如 `理智`。但新手阶段优先写全 `say 理智 mara_vane`，最不容易弄错。

### 4.3 不清楚任务时输入 `journal`

游戏中的案件、线索、失败代价和下一步目标会记录在你的**线索册**中：

```text
journal
```

它与 `inv` 不同：

| 指令 | 查看内容 |
|---|---|
| `inv` | 你实际携带的物品，例如便签、钥匙或装备 |
| `journal` | 你已经知道的案件、不可带走的证据、当前目标、失败后的可行下一步 |

你可以只看某一个案件：

```text
journal otherworld_train
journal storm_eye
```

## 5. 6 号车厢：第一段标准教学流程

你在列车中醒来后，请按这个顺序体验一次。每一步都在教一种后续会反复使用的能力。

```text
look
say 理智 mara_vane
get mysterious_note
look mysterious_note
look train_map
journal
save
go east
```

这段流程分别代表：

| 步骤 | 你学到什么 | 为什么重要 |
|---|---|---|
| `look` | 观察环境、出口和 ID | 绝大多数任务从场景观察开始 |
| `say 理智 mara_vane` | 向 NPC 获取规则 | NPC 对话会给出主题、风险和行动方向 |
| `get mysterious_note` | 拾取物品 | 只有可携带物品会进入 `inv` |
| `look mysterious_note` | 调查物品 | 同一物品可能含有职业专属或技能相关信息 |
| `look train_map` | 调查固定场景物 | 有些线索不能带走，但会写入 `journal` |
| `journal` | 回看案件状态 | 避免忘记线索或靠试错推进 |
| `save` | 主动保存 | 在进入危险车厢、阅读禁书或准备下线前使用 |
| `go east` | 继续前进 | 移动前先确认出口和当前目标 |

> **推荐习惯：** 每拿到关键线索、进入危险区域前、准备退出游戏前，各输入一次 `save`。

## 6. COC 基础：HP、SAN、技能与失败

### 6.1 HP：身体还能承受多少伤害

输入：

```text
hp
```

可以查看当前生命与技能。HP 降到 0 时，角色会倒下并回到安全位置；这通常不会删除你的存档，但会让你付出位置、节奏或剧情上的代价。

### 6.2 SAN：你还能否把眼前所见当作现实

SAN 是理智值。可怕的场景、异常知识或怪物可能降低 SAN。SAN 低并不意味着游戏立刻结束，但它意味着风险在上升。遇到未知事物时，不要为了“看全内容”而反复触发危险描述；必要时撤退、保存或先整理线索。

### 6.3 技能检定：`perform <技能> [目标]`

技能不是菜单按钮，而是通过命令使用。例如：

```text
perform 侦查
perform 急救 dying_conductor
perform 潜行
```

场景会尽量提示可用的技能与目标。若没有提示，先 `look`，再查看：

```text
help skills
```

检定失败并不必然是死路。当前列车版本会把关键失败的代价和替代行动写入 `journal`。例如 3 号车厢第一次侦查没找到机关时，可再试一次，或选择潜行；第二次侦查会确保你发现电路开关。

### 6.4 战斗与逃跑

遇敌后，系统会自动进入战斗。你不能在战斗中正常移动，但可尝试：

```text
flee
```

逃跑存在判定，失败后可以再次尝试；你也可以正面攻击：

```text
kill clicker
```

不过新手的优先级应当是：**先逃离，后战斗；先观察，后尝试技能。** 消防员相对适合正面冲突，记者更适合侦查与路线判断，列车员更适合利用列车机关。

## 7. 3 号车厢：如何处理怪物与黑暗

3 号车厢是对“信息、风险和退路”的综合测试。进入前建议先：

```text
save
journal
```

车厢内可以尝试：

```text
perform 侦查
```

你可能发现 `circuit_switch`。找到后可选择：

```text
toggle circuit_switch
perform 潜行
```

开灯会提高怪物注意力，但也会降低潜行难度；不开灯则更隐蔽，却更难确认机关。两种选择都可推进。

如果潜行失败、怪物出现，请不要慌。你的选择至少有三种：

```text
flee
kill clicker
journal
```

`journal` 会记录刚才失败的代价和可行方案。它不是“失败记录”，而是让你不用背诵路线也能重新做决策的工具。

## 8. 到 1 号车厢后怎么办？

1 号车厢是列车教学剧情的收束点。普通离车路线是：

```text
look
operate
go east
go north
```

如果背包里已有乘务员钥匙，则可以先尝试更深层的路线：

```text
use conductor_key
touch mysterious_entity
operate
go east
```

不想承受额外 SAN 风险时，直接走普通离车路线即可。不要向西硬退，那里会带来伤害和理智代价。

## 9. 出列车后：州街与《暴风之眼》

列车结束后，剧情会把你带到新的调查区域。进入州街后，先 `look`，并留意 NPC 的提示。州街的气象记录员诺亚·格兰特可以提供后续章节的铺垫：

```text
say 暴风 noah_grant
say 书店 noah_grant
say 准备 noah_grant
```

无名旧书店是《暴风之眼》的章节入口。标准探索顺序是：

```text
look
say 帮助 elias_thorne
search 书架
save
read 暴风之眼
journal storm_eye
```

《暴风之眼》现在是后续章节的预告入口。阅读后会在你的线索册中留下个人标记；它不会因为别的玩家已经找过书架而失效。

## 11. 常见问题与排查

### 我不知道输入什么

依次输入：

```text
look
help
journal
```

然后观察页面中的 `【操作提示】`。这些提示是当前场景最可靠的下一步，而不是装饰文本。

### 我看到了中文名和方括号 ID，该用哪个？

优先使用方括号中的 ID。例如看到 `玛拉·维恩 [mara_vane]`，就输入：

```text
say 理智 mara_vane
```

### 我找不到刚才的物品

先输入：

```text
inv
journal
```

可带走的物品在 `inv`；不可带走的证据和已读线索在 `journal`。

### 我在战斗中走不动

战斗中不能正常 `go`。可以尝试：

```text
flee
```

或使用 `kill <敌人ID>`。如果刚刚失败过，先输入 `journal`，查看场景是否提供机关、技能或撤退建议。

### 我登录后输入框仍像密码框

请刷新网页一次，建议使用 `Ctrl+Shift+R`。当前版本会在登录成功后自动恢复普通文本输入；只有明确出现“请输入密码”或“请再次输入密码”时才会显示为密码框。

### 我怎样确定已经保存？

输入：

```text
save
```

看到 `【存档】已保存。地点：...` 即表示当前角色数据已写入。正常输入 `bye` 下线也会保存，但重要节点仍建议手动 `save`。

## 12. 新手的第一晚：最短清单

如果你不想先读完整教程，只记住下面这 10 条即可：

1. 每到新地点先 `look`。
2. 看见 NPC 先 `say 帮助 <NPC ID>`。
3. 看见方括号 ID 就记录它；命令优先用 ID。
4. 不知道下一步就 `journal`。
5. 物品在 `inv`，线索和目标在 `journal`。
6. 进入危险车厢前先 `save`。
7. 战斗时先考虑 `flee`，不要把硬打当成唯一选择。
8. 检定失败后别盲目重复，先看 `journal` 给出的替代方案。
9. 6 号车厢先调查便签、示意图和玛拉，再向东。
10. 退出前输入 `save`，然后 `bye`。

> 这列车奖励谨慎的好奇心，不奖励无目标的试错。你不需要知道所有答案；你只需要知道如何把答案留在自己的线索册里。
